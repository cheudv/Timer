# 时录 · 计时统计

一款拥有众多精美主题的专注计时与统计工具。基于 Electron 构建，支持**桌面端**与**网页端**双模式运行。按板块记录每一次专注会话，用按日 / 按周 / 按月的折线图洞察你的时间分布，并通过打卡累积积分，兑换酷炫的限定主题。

## 功能特性

- **多板块计时**：自由添加「学习计时」「工作计时」等板块，拖拽排序，一键切换。
- **计时持久化**：即使完全关闭软件，正在进行的计时也不会丢失，重启后自动续算，一秒不差。
- **数据全本地**：所有数据保存在本机，不联网、不上传云端。
- **日 / 周 / 月统计**：单次最高、周平均、周最高等指标卡片 + 可切换统计粒度的折线图。
- **打卡日历**：按月查看每个板块的打卡记录，每天记录时长一目了然。
- **积分兑换**：每日计时打卡累积积分，兑换限定主题。
- **主题系统**：8 款基础主题跟随板块颜色自动切换，另有 3 款可兑换的限定主题（全元素重设计）。
- **会话备注**：为每次会话添加备注，随时回看当时所想。

## 计时长久化：数据如何被可靠保存

这是本项目的核心设计：**计时永不丢失、数据永不损坏**。

### 数据存哪里

| 运行模式 | 数据目录 |
| --- | --- |
| 桌面端（Electron） | `%APPDATA%\时录\store.json` |
| 网页端（`node server.js` / `start.bat`） | 同上，默认 `%APPDATA%\时录` |
| 自定义 | 设置环境变量 `SHILU_DATA_DIR` 即可重定向数据目录 |

所有数据都落在一个 JSON 主文件 `store.json` 中，内部结构：

```jsonc
{
  "boards": [/* 板块：id / name / color / theme */],
  "records": [/* 会话记录：boardId / start / end / dur */],
  "ui": { "lastBoard": "", "lastView": "timer", "running": null, "defaultTheme": "" },
  "themeUnlocks": { "板块id": { "主题key": 时间戳 } }
}
```

### 三重保护机制

数据写在 `server.js` 中经过了三层保险：

1. **原子写入**（`atomicWrite`）：先写临时文件再 `rename` 覆盖，避免写入中途崩溃造成文件损坏。
2. **写前备份**（`.bak`）：每次写盘前自动把当前文件复制为 `store.json.bak`，出问题可手动恢复。
3. **每日快照**（`backupDaily`）：每天首次保存时生成一份 `store-YYYY-MM-DD.json` 归档，回溯到任意一天。

### 计时为什么会"关掉软件也不停"

秘密在于：**计时的是时间戳，而不是程序本身**。

1. 点下「开始」的瞬间，`{ boardId, start: Date.now() }` 会被**立即写盘**（`save(true)` 同步保存到 `ui.running`）。
2. 之后无论最小化、关窗口，还是彻底退出软件，这条开始时刻都已躺在磁盘上。
3. 下次启动时，`init()` 检测到 `ui.running`，用 `当前时间 - 开始时刻` 精确续算总时长，并提示「已恢复计时中」。
4. 想结束这次计时，点一下「停止」即可把整段时长保存成一条会话记录。

> 所以它**不是后台偷偷计时**——程序确实已彻底退出。只是因为「开始时刻」被记在了本机，重开时数学上能把中间所有时间都补回来。

### 命令行停止计时

如果计时进行中软件却无法正常停止，可用脚本直接落盘：

```bash
stop-timer.bat     # 检测到软件在运行会先提示，避免数据被覆盖
```

`stop-timer.js` 会读取 `ui.running`，把从开始到此刻的时长写为一条记录，并同样执行原子写入 + 每日备份。

### 保存策略

- 前台操作（开始 / 停止 / 添加板块 / 兑换主题）都会立即保存。
- 常规改动走 300ms 防抖合并，减少磁盘写入次数。
- 全部保存经由本地 HTTP 服务 `POST /api/store`，对格式有校验，拒绝损坏数据。

### 数据备份 / 恢复建议

整个 `%APPDATA%\时录` 目录拷走即完成备份，拷回即恢复。里面：

- `store.json` 主数据（当前最新）
- `store.json.bak` 写前备份
- `store-*.json` 每日归档快照

## 精美主题：从颜色到整个宇宙的切换

主题系统分两层：**跟随板块的基础主题** 与 **积分兑换的限定主题**，都只需一键切换。

### 8 款基础主题

每个板块在创建时选择一种颜色，颜色即主题——8 种颜色对应 8 套完整的视觉设计，包括背景、卡片、文字、主色、图表配色与星空粒子：

| 颜色 | 主题 key | 视觉基调 |
| --- | --- | --- |
| 翡翠绿 | `emerald` | 森林夜曲，萤火虫在深绿间游荡 |
| 珊瑚橙 | `coral` | 落日熔金，余烬缓缓升腾 |
| 琥珀黄 | `amber` | 烛光暖黄，尘埃光柱流转 |
| 极光蓝 | `arctic` | 寒夜极光，雪花轻落 |
| 星紫（默认） | `galaxy` | 星云深邃，流星划过 |
| 樱粉 | `sakura` | 月下樱吹雪，花瓣飘零 |
| 深海青 | `abyss` | 深海光柱，气泡上升 |
| 晨雾绿 | `mist` | 晨雾缭绕，雾团缓缓游移 |

每个主题包含 **40+ 个 CSS 变量**（背景 / 卡片 / 线条 / 输入框 / 弹窗 / 文字 / 按钮 / 图表轴色 / 图表线条等），外加一套 **Canvas 粒子场景**（星星、萤火虫、余烬、飘雪、花瓣、气泡、雾团、尘埃、字符雨……），整套 UI 与动态背景浑然一体。

### 限定主题：积分兑换

在「积分兑换」商城（顶栏积分按钮）中，可以用每个板块自己的积分兑换限定主题。积分规则：**每个有记录的打卡日 +1 分**，兑换一次消耗 3 分，主题仅对兑换它的板块生效。

| 主题 | key | 设计亮点 | 粒子场景 |
| --- | --- | --- | --- |
| **CRT 终端** | `mono` | 复古磷光绿屏：扫描线闪烁、网格地面、方块光标跳动，全部元素方角重设计 | 代码字符雨 + 绿色磷光星点 |
| **赛博霓虹** | `cyberpunk` | 数字雨倾泻的赛博之夜：品红 × 青色霓虹对撞、板块名故障抖动 | 全息网格 + 雨线 + 霓虹粒子 |
| **烟雨荷塘** | `lotus` | 烟雨荷塘：细雨敲开涟漪，荷花碧波间摇曳，衬线字体 +「」书名号标题 | 细雨 + 荷花 + 荷叶 + 涟漪 |

### 主题切换的几种方式

1. **按板块自动切换**：点击顶部板块标签即切换该板块的主题（板块有自己的颜色/主题）。
2. **默认主题**：设置里选择「默认主题」，无板块激活（如空列表）时使用，新建板块默认选中该色。
3. **限定主题全局预览**：在商城里点「预览」，顶部会出现预览条，全局换装查看效果；预览期间禁用计时，点「退出预览」即可恢复。满意再决定是否兑换。
4. **兑换后应用**：兑换即自动应用到该板块；「恢复默认主题」可随时撤销。

### 主题如何实现

- `app.js` 中 `THEMES` 定义每款主题的 CSS 变量与星空中粒子配色，`SCENES` 定义粒子场景。
- 切换主题 = 给 `<html>` 换 `theme-<key>` class + 写入 CSS 变量 + 重建 Canvas 粒子场景，秒级切换零闪烁。
- 限定主题在 `style.css` 里还有一整块 `html.theme-<key>` 全量样式，重绘按钮、卡片、弹窗、滚动条等所有细节。

### 想新增一款主题？

作者在代码里预留了模板，新增限定主题只需 4 步：

1. 在 `app.js` 的 `THEMES` 中添加同名 key（CSS 变量 + 粒子配色）；
2. （可选）在 `SCENES` 中添加专属粒子场景，不添加则回退到 galaxy；
3. 在 `style.css` 中复制 `html.theme-mono` 样式块，改为 `html.theme-<key>` 重设计全部元素；
4. 在 `app.js` 的 `LIMITED_THEMES` 注册 name / desc / cost / accent，商城会自动出现该主题。

## 快速开始

需要 Node.js（建议 v18+）。

```bash
npm install
```

### 桌面端

```bash
npm start
```

### 网页端

```bash
start.bat
```

或手动执行：

```bash
node server.js
```

然后浏览器访问 http://127.0.0.1:3000 （端口被占用时自动切换到随机端口）。

> 注意：直接打开 `index.html` 无法保存数据，必须通过 `node server.js` 启动。

## 辅助脚本

| 脚本 | 说明 |
| --- | --- |
| `start.bat` | 网页版启动入口（Node 服务器） |
| `start-rest.bat` | 添加「休息」计时板块 |
| `stop-timer.bat` | 停止当前计时并落盘为一条记录 |

## 构建发布

打包 Windows 便携版（生成 `dist/时录-portable.exe`）：

```bash
npm run dist
```

仅生成免安装目录（用于调试）：

```bash
npm run pack
```
